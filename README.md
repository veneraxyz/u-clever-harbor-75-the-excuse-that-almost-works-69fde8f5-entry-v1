A gamer's SMS excuse to their boss for skipping work during GTA 6 release week — one line, written like a real person in a hurry. A burst kitchen pipe at 6am, a plumber who can only come this morning, and a flat that floods if nobody stays home: specific, small, and just believable enough that a tired manager almost buys it.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output npx tsx main.ts
```

Writes one line (99 characters, 20 words) to `entry.txt`.
